# MathGeoCraft (課本幾何復刻神器) 📐

專為數學老師量身打造的**零設定、零伺服器、零付費、免 API Key** 開源網頁工具。

老師只需按下 `Ctrl + V` 貼上題目截圖，即可利用智慧半透明對照底圖與幾何吸附引擎，在 10 秒內復刻出教科書／習作印刷等級的高解析幾何圖檔 (300+ DPI PNG)，並一鍵匯出排版完成的 Word 試卷檔 (`.docx`)！

---

## 🌟 核心特色

1. **零成本、零門檻 (Zero Config & Zero Cost)**：
   - 100% 純前端（HTML5 + CSS + JavaScript），無任何後端伺服器依賴。
   - 不需要註冊帳號、不需串接任何付費 AI API，也不會過期。
   - 可直接放上 **GitHub Pages** 永久免費託管給所有人使用。

2. **考卷截圖直貼 (`Ctrl + V`)**：
   - 截下課本、講義或手機拍下的幾何題目，切換到網頁直接按 `Ctrl + V` 貼上。
   - 圖片自動成為半透明對照底圖（透明度隨選，按 `Space` 空白鍵可隨時切換對照）。

3. **課本習作印刷美學規範**：
   - **標準線條規格**：主輪廓實線 1.8pt 純黑、輔助虛線 1.2pt、直角折角符號 $\llcorner$、等長雙斜線標記。
   - **專業數學排版**：頂點字母採用 *Times New Roman* 數學斜體（$A, B, C$），內建文字白色外光暈（Halo），與線條交會時永不雜亂。

4. **一鍵教科書經典樣板**：
   - 內建：直角三角形、等腰三角形（含高線）、正三角形、平行四邊形、等腰梯形、圓內接三角形（含圓心 $O$）、圓內接四邊形、直角坐標系等。
   - 點一下樣板即放入畫布，只要拖曳頂點對齊底圖，幾秒內搞定！

5. **多模態極速匯出**：
   - **📋 複製圖片**：一鍵複製 300+ DPI 超高解析度圖至剪貼簿，切回 Word 即可直接 `Ctrl + V` 貼上。
   - **🖼️ 下載 PNG**：支援純白底或透明底高清圖下載。
   - **📐 下載 SVG**：純向量圖，可直接拖進 Word 並右鍵「轉換為圖案」進行解散群組編輯。
   - **📄 產生 Word 檔 (`.docx`)**：純前端在老師電腦本機組裝出排版工整的試卷檔（左側題目敘述、右側高解析幾何圖、下方作答區）。

## 🚀 快速開始 (Quick Start)

### 方式一：直接在瀏覽器開啟
不需要任何環境或建置工具，直接用瀏覽器（Chrome / Edge / Firefox / Safari）雙擊打開 `index.html` 即可立即使用！

### 方式二：本地輕量伺服器
如果您習慣用 Python：
```bash
cd MathGeoCraft
python -m http.server 8080
```
開啟瀏覽器前往 `http://localhost:8080`。

### 方式三：免費部署到 GitHub Pages (分享給全年級老師)
1. 在 GitHub 上建立一個公開倉庫（如 `MathGeoCraft`）。
2. 將本專案檔案 push 到該倉庫。
3. 進入 GitHub 倉庫的 **Settings → Pages**，在 **Branch** 選擇 `main` / `root` 並按 Save。
4. 即可獲得一個全世界老師都能直接點開使用的永久網址：
   `https://<你的帳號>.github.io/MathGeoCraft/`

## ⌨️ 常用快捷鍵

| 快捷鍵 | 功能說明 |
| :--- | :--- |
| <kbd>Ctrl</kbd> + <kbd>V</kbd> | 貼上截圖為半透明底圖 |
| <kbd>Space</kbd> (空白鍵) | 快速切換 底圖 顯示／隱藏對照（課本印刷檢視） |
| <kbd>V</kbd> | 切換至「選取與移動」工具 |
| <kbd>P</kbd> | 切換至「實線多邊形」連續打點繪製工具 |
| <kbd>D</kbd> | 切換至「輔助虛線」工具 |
| <kbd>R</kbd> | 切換至「直角記號」工具 |
| <kbd>A</kbd> | 切換至「角度圓弧」工具 |
| <kbd>C</kbd> | 切換至「圓形」工具 |
| <kbd>Delete</kbd> / <kbd>Backspace</kbd> | 刪除選取的頂點、線段或標記 |
| <kbd>Ctrl</kbd> + <kbd>Z</kbd> | 復原上一步 (Undo) |
